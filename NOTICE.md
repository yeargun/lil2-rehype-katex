# Notice

lil2-rehype-katex is a LilScript reimplementation of [rehype-katex](https://github.com/remarkjs/remark-math)
7.0.1, with what it uses to read KaTeX's output: hast-util-from-html-isomorphic 2.0.0 (hast-util-from-dom,
hast-util-from-html / parse5 for the HTML KaTeX writes), hastscript's property parsing (property-information 7.2.0)
and hast-util-to-text, © Titus Wormer, MIT. KaTeX itself is the `katex` package (© Khan Academy and other
contributors, MIT), used as is. It embeds lil2-remark-math, lil2-mdast-util-to-hast, lil2-mdast-util-from-markdown
and lil2-micromark.
